Dune Clash never asks you to sign up. You open it and play, as a guest. That is pleasant on day one and risky on day thirty: a guest base belongs to one device. This page shows how to make it safe, in about a minute.

## How your base is stored

Your base itself is kept on the game's server. What your device keeps is the **key**: a random identifier, created on first launch, that says "this base is mine".

- Lose the device, reset it, delete the game or clear the browser's data, and the key is gone. The base is still on the server, but nothing can open it.
- **Saving** means tying the base to something that outlives the device: your Game Center account, your Google account, or a second device.

The menu tells you where you stand. Tap ☰ on your base. If it says "Your base is only on this iPhone" and the ☰ button carries a dot, you have not saved yet.

## On iPhone: save with Game Center

1. Make sure you are signed in to Game Center (iPhone Settings, Game Center).
2. In Dune Clash, tap ☰.
3. Tap **Save progress with Game Center**.

The menu now reads **Progress saved to Game Center**. Done.

**On a new iPhone:** sign in to the same Game Center account, install Dune Clash, open ☰ and tap **Save progress with Game Center**. The game finds your saved base and asks **Load saved base?**, showing its name, Citadel level and trophies. Tap **Load**.

## On Android: save with Google

The same, with your Google account:

1. In Dune Clash, tap ☰.
2. Tap **Save progress with Google** and choose your account.

On a new Android phone, install the game, tap the same button with the same account, then **Load**.

The game keeps only an ID number for your account, so that it can find your base again. It does not store your e-mail address, and it never sees a password.

## Any device to any device: the transfer code

Game Center lives on Apple devices and Google saving in the Android app. To cross between them, or to move a base out of a web browser, use a transfer code. It works between **iPhone, Android and the browser, in any direction**.

{{shot:code|A transfer code: twelve characters, valid once, for 15 minutes.}}

**On the device that has the base:**

1. Tap ☰.
2. Under **Another phone?**, tap **Show code**.
3. A code appears, in the form XXXX-XXXX-XXXX.

**On the device that should get it:**

1. Open Dune Clash and tap ☰.
2. Tap **Enter code** and type the code. Capitals and dashes do not matter.
3. The game shows which base the code is for: name, Citadel level, trophies. Check that it is yours.
4. Tap **Load**.

A few things to know:

- **The code works once and for 15 minutes.** If it runs out, make a new one.
- **The base stays on the first device too.** After the transfer both devices open the same base. Nothing is copied or split: it is one base with two keys.
- **The base that was on the second device is replaced.** If it was never saved anywhere, it is deleted, and the game warns you before you confirm. If you care about it, save it first.
- **Then save on the new device as well**, with Game Center or Google, so that it is tied to your account there.

### Never share a transfer code

Whoever types the code gets your base. All of it, for good. Nobody from Sandstorm Game will ever ask you for one. A stranger who offers crystals, help or a "trade" in exchange for a code is trying to steal your base.

## Common situations

**I am getting a new iPhone.** Save with Game Center on the old one now. On the new one, sign in to Game Center, install the game, tap Save progress with Game Center, then Load.

**I am switching from iPhone to Android, or the other way.** Use a transfer code while you still have the old phone. Then save with Google or Game Center on the new one.

**I started in a browser and now have the app.** Show code in the browser, Enter code in the app, then save in the app. Your base keeps working in the browser as well.

**I want to play on my phone and my tablet.** Move the base with a code. Both devices then open the same base. Play on one at a time.

**I play in a browser and have no phone app.** Open the game in a second browser, or on a second device, and move the base there with a code. Now two places hold the key. See [playing in your browser](/blog/play-dune-clash-in-browser/).

**My phone was lost or broken.**

- If you had saved with Game Center or Google: install the game on the new phone, tap the save button with the same account, and load the base.
- If the base is also open on another device or browser: make a code there.
- If neither: we are sorry, but the base cannot be recovered. With no account and no second key, nothing connects you to it. That is the price of a game that asks for no e-mail address, and the reason this page exists.

**I started a new base by accident and want my old one.** If the old one was saved, tap **Save progress with Game Center** (or **Google**) with the same account. The game finds the saved base and offers to load it.

## Changing your commander name

The name other players see is in the same menu: tap ☰, edit the name at the top (up to 16 characters) and tap **Save**. Pick something that is not your real name.

## Deleting your account

If you want to leave for good, tap ☰, then **Delete account**, then confirm with a second tap. The base, its progress, any unused crystals and the link to Game Center or Google are erased from the server at once. This cannot be undone.

If you cannot open the game, write to the address on the [support page](https://dune-of-clash.vercel.app/support.html) with your commander name.

## A one-minute checklist

1. Tap ☰. Is there a dot on the button, or a line saying your base is only on this device?
2. If yes, tap **Save progress with Game Center** or **Save progress with Google**.
3. In a browser, put the base on a second device with **Show code**.
4. Tell nobody your codes.

That is all. Now your base survives your phone. Back to [the game](/dune-clash/), or on to the [FAQ](/blog/dune-clash-faq/).
